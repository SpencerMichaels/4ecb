# M5.7 invited-beta deployment status

Working checklist for hosting 4ecb for the product owner's D&D group. Operator
instructions live in [`public-deployment.md`](public-deployment.md) under
"Small-group deployment with Compose"; this file tracks what has been verified.

Last updated: 2026-10-16 (commit `a356841`).

## Done

- `compose.yaml` runs the hardened production image (read-only root, bounded
  `/tmp`, loopback-only port via `FOURECB_PORT`, image tag via `FOURECB_TAG`).
- The image serves `/private-packs/` from a read-only mount; no reverse-proxy
  rules are needed to advertise a pack.
- `pnpm content-tool advertise <pack.4ecp>` validates a pack, copies it to
  `deploy/private-packs/<packId>-<digest prefix>.4ecp`, and writes
  `deploy/runtime-config.json`. `deploy/` is ignored by git and the Docker build
  context.
- Local container check (2026-10-16, port 18080): the image builds with
  `docker compose up -d --build`; `/healthz` returns `ok`; the runtime config
  advertises `local-wotc-and-custom` (`c5a0e8cb…`); the 5.8 MB pack downloads
  in full; a missing pack returns 404; security headers are present; Docker
  reports the container healthy.
